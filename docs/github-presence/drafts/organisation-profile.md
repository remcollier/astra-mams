# ASTRA & MAMS

Build agents on the JVM, expose their capabilities as web services, and connect them to the Web of Things.

**ASTRA** is an agent-oriented programming language with beliefs, goals and event-driven plans. Its Java integration lets agent programs use JVM libraries alongside their reasoning logic.

**Multi-Agent Microservices (MAMS)** brings agents into microservice applications. Its ASTRA–CArtAgO implementation lets agents expose HTTP resources, observe changes and decide how requests are handled.

**MAMS WoT** lets those agents interact with devices described by W3C Web of Things Thing Descriptions, including HTTP, CoAP and MQTT devices.

## Development and contributions

The repositories here mirror development on GitLab. You can browse, clone and fork them on GitHub; please use the upstream GitLab projects for issues and merge requests. Each repository links its development home.

ASTRA and MAMS are research software developed at University College Dublin. Contributions, examples and feedback are welcome.
