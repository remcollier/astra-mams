# Contributing

Thanks for your interest in improving this project. Bug reports, documentation fixes, examples and implementation contributions are welcome.

## Where to contribute

This GitHub repository is a one-way mirror of its GitLab development repository. The README links the exact upstream project. Please open issues and merge requests there so discussion and review stay together.

You may clone or fork this mirror to explore the code. To propose a change, fork the upstream GitLab repository, push your branch there and open a merge request. GitHub pull requests are not automatically transferred to GitLab; a maintainer may close one with a link to the contribution route.

## Reporting a problem

Include the project and dependency versions, Java and Maven versions, what you expected, what happened, and the smallest example that reproduces it. Include relevant error output with credentials and personal information removed.

## Proposing a change

Start a discussion upstream for substantial API or architecture changes. Keep a merge request focused and explain its user-visible effect. Run the checks documented by the affected project or module and report which checks passed, failed or could not be run.

For documentation examples, verify the advertised commands and dependency versions. Do not update tutorial version numbers solely to match a newer release without checking the example.

Preserve existing copyright and licence notices. Do not add credentials, private data or generated build outputs.

## Mirror maintenance

Changes to README files and this contribution policy must also go through GitLab. Direct GitHub commits can break mirroring. GitLab remains the authoritative record of development until a separately announced migration.
