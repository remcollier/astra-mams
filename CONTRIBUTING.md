# Contributing

This repository contains the public ASTRA/MAMS landing page and plans for its GitHub presence. Documentation improvements here can be proposed through a GitHub pull request.

For language, runtime, service framework or Web of Things changes, use the appropriate upstream GitLab project:

- [ASTRA core](https://gitlab.com/astra-language/astra-core)
- [MAMS reference implementation](https://gitlab.com/mams-ucd/mams-cartago)
- [MAMS Web of Things](https://gitlab.com/mams-ucd/mams-wot)
- [ASTRA guide](https://gitlab.com/astra-language/astra-docs)

Include relevant versions and a small reproducing example when reporting a problem. Keep credentials and private data out of reports and commits.

The mirror contribution policy in `docs/github-presence/drafts/CONTRIBUTING.md` is a draft for future mirrored implementation repositories; it does not govern this landing repository.
